# بوابات الجودة والإيقاع البصري

اقرأ هذا المرجع عند تنظيف تسجيل جديد، إضافة صور أو بطاقات، أو فحص ملف ناتج من محرر Chrome.

## مرحلتان لا تختلطان

1. **نسخة نظيفة:** ثبّت القص، نهايات الكلمات، النص المصحح، وتزامن الكابشن.
2. **نسخة بصرية:** أضف الصور والبطاقات والموشن فوق النسخة النظيفة من دون إعادة قص الكلام.

إذا تغيّر القص أو الصوت بعد بدء التصميم، أعد بناء الكابشن وراجع النسخة النظيفة قبل متابعة المشاهد. لا تسجّل موافقة نيابة عن المستخدم؛ يكفي في العمل المعتاد أن تعرض معاينة واضحة وتوثّق ما تغيّر.

## اختيار الصورة أو العنصر

اسأل عن وظيفة الجملة، ثم استخدم أصغر عنصر يشرحها:

| وظيفة الجملة | العنصر الأنسب |
|---|---|
| مقارنة خيارين | بطاقة مقارنة أو تقسيم جانبي |
| خطوات أو علاقة | مخطط عقد ومسار |
| شرح أداة أو واجهة | لقطة شاشة حقيقية ومقروءة |
| رقم أو نتيجة مؤكدة | رقم كبير مع سياق مختصر |
| فكرة أو تحذير قوي | عنوان إيقاعي عالي التباين |
| دعوة للخطوة التالية | كرت CTA بسيط |

لا تضف صورة لمجرد ملء الشاشة. احتفظ بوجه المتحدث عندما لا تضيف الصورة معنى أو دليلًا.

## الأنماط البصرية المعتمدة

- `editorial`: الافتراضي للتعليم والرأي؛ خلفية نظيفة، كحلي وبرتقالي، بطاقات ذات تسلسل واضح.
- `diagram`: للفانل، الأتمتة، الخطوات والعلاقات؛ عقد قليلة ومسار مقروء من اليمين إلى اليسار.
- `signal`: للهوك أو لحظة حاسمة واحدة؛ تباين قوي وحركة قصيرة، لا يستخدم طوال الفيديو.

هذه أنماط تنظيم وليست قوالب جامدة. لا تغيّر النمط داخل الفيديو إلا عند انتقال معنوي واضح.

## سجل العناصر ومصادرها

اكتب العناصر داخل `visual-plan.json` على التايم لاين النظيف:

```json
{
  "mode": "editorial",
  "items": [
    {
      "start": 2.4,
      "end": 5.8,
      "purpose": "demonstrate",
      "kind": "screenshot",
      "title": "الربط داخل النظام",
      "path": "assets/app-screen.png",
      "source": "لقطة شاشة قدّمها المستخدم بعد إخفاء البيانات الخاصة"
    }
  ]
}
```

القيم المفيدة لـ`purpose`: `compare`، `connect`، `demonstrate`، `count`، `invite`.

- كل صورة حقيقية تحتاج `source` واضحًا.
- افحص الأسماء وأرقام الهواتف والمفاتيح وبيانات العملاء قبل العرض.
- لا تستخدم شعارًا مولدًا بدل الشعار الرسمي.
- الرسم التوضيحي يشرح فكرة، لكنه ليس دليلًا على أن النظام مطبق أو أن النتيجة تحققت.

## فحص التصدير

بعد تنزيل الملف من محرر Chrome أو بعد الرندر المحلي، شغّل:

```bash
python3 scripts/17_verify_export.py <video.mp4> --work <work>
```

الفحص يرفض الملف إذا كان ناقص المدة، بلا صوت، صامتًا عمليًا، غير قابل للفك حتى النهاية، أو يحتوي تجمّدًا طويلًا غير مقصود. افحص بصريًا البداية والمنتصف والنهاية أيضًا؛ نجاح الفحص التقني لا يحكم على جودة الفكرة.
